# APAC TA Employer Monitor

亚太区人才招聘（TA）竞品与雇主动态看板：公司矩阵、签证政策摘要、薪酬对标示意、时间线动态等。**数据为示意**，发布前请按业务需要更新 `web/index.html` 中的内嵌 JSON。

## 本地预览

双击 `web/index.html`，或：

```powershell
cd web
python -m http.server 8766
# http://127.0.0.1:8766/
```
